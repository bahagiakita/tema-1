# 📚 Dokumentasi Proyek Earthy Botanical — BahagiaKita

Selamat datang di pusat dokumentasi template undangan pernikahan digital **Earthy Botanical**. Seluruh panduan penggunaan, arsitektur aset, konfigurasi multi-agama, dan integrasi backend tersusun dalam panduan-panduan berikut:

---

## 🗂️ Daftar Panduan

1. [**Panduan Penggunaan Utama (`PANDUAN-PENGGUNAAN.md`)**](./PANDUAN-PENGGUNAAN.md)
   - Arsitektur folder aset & gambar (`images/`)
   - Alur pengolahan foto klien (Otomatisasi Sharp, Couple Split & Visual Web Cropper)
   - Finalisasi produksi & minifikasi cerdas (`npm run finalize`)
   - Master template safety vault & 1-click restore (`npm run template:restore`)
   - Panduan deployment ke GitHub Pages (`.nojekyll`, `404.html`, `.gitignore`)
   - Cheat sheet perintah NPM & launcher `.sh`

2. [**Panduan Sistem Multi-Agama (`PANDUAN-MULTI-AGAMA.md`)**](./PANDUAN-MULTI-AGAMA.md)
   - Matriks narasi sakral 6 agama (Islam, Kristen, Katolik, Hindu, Buddha, Universal)
   - Aturan pemilihan aset visual pada Mode Tanpa Foto (`hasPhotos: false`)
   - Cara kustomisasi manual (*override*) kutipan kitab suci

3. [**Panduan Setup Supabase Database (`SUPABASE-SETUP-GUIDE.md`)**](./SUPABASE-SETUP-GUIDE.md)
   - Cara setup tabel RSVP / Ucapan & Doa tamu undangan
   - Konfigurasi Row Level Security (RLS) & Anon Key yang aman
   - Skrip SQL generator otomatis (`npm run gen:sql`)
